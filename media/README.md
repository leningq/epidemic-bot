# Картинки обучения

Положите сюда файлы с точно такими именами:

| Файл | Где показывается |
|---|---|
| `tutorial_begin.jpg` | первое сообщение /start с кнопками «Начать путешествие / Отказываюсь» |
| `tutorial_end.jpg` | финал обучения |
| `tutorial_end.mp4` | анимация после финала (необязательно) |

Сейчас `tutorial_begin.jpg` и `tutorial_end.jpg` — **временные заглушки** (чашка Петри и этикетка
образца, 1280×720). Арт оригинального бота не используется из-за авторских прав. Замените их своими
картинками с теми же именами, когда они будут готовы.

- Файла нет — бот отправит тот же текст без картинки.
- Папка подключена к контейнеру напрямую: перезапуск и пересборка не нужны.
- Чтобы заменить картинку, просто положите новый файл с тем же именем — бот загрузит его заново.
