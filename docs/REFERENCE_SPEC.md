| Элемент | Как в оригинале |
|---|---|

| Разделитель | `❇️—❎—✳️—💚—✳️—❎—❇️` (зелёные квадраты, по центру 💚) |

| Кнопки | inline, по одной в ряд (обучение), по 3 в ряд (1x/3x/5x), 2 в ряд (страницы биотопа) |
| Ответ на команду | прокачка — **reply** с цитатой сообщения игрока; заражение, списки, топы — обычное сообщение |

| Ссылки на игроков | синие имена-ссылки (`tg://openmessage?user_id=…`) |
| Команды в тексте | синие ссылки, подставляющие команду в поле ввода (`https://t.me/<бот>?text=…`) |

## 3. Не показано на скринах — сверяем с исходным кодом оригинала

| Экран | Что поправить до 1:1 |
|---|---|
| Досье «лаб» | `——[ Характеристика]——`, `—[Запасы — реагентов]—` (без лишних пробелов); строка премии статичная: «⏱ <i>Ежедневная премия через: Каждый день в 12.00 и 00.00</i>»; «😓 Ученый в состоянии горячки ещё …»; горячка в скобках летальности: ÷3, минимум 1, при ≥180 → 60; кнопки 🧪🧑‍🎤💉/🪬💊🕵️‍♂️ видны всем (чужим — «Не для тебя моя кнопочка росла») |
| `+навык` (цена) | тексты превью по навыкам дословно (включая пробел после «»», «био-ресурса» у летальности) |
| Провал заражения | «… Осталось патогенов: N\n Шкала пробития: X% » (без эмодзи перед «Шкала») |
| Горячка / КД | «…горячка, вызванная X Придётся отлежаться…», «Время выздоровления …», форматы времени оригинала: «1 часов 5 минут 3 секунд», «5 минут» |
| Сам себя / бот | дословные тексты оригинала («…на пределе, допустимости…», «…сущность умеющую дышать») |
| Уведомления СБ | «🕵️‍♂️ Служба безопасности лаборатории … докладывает:» — дословно |
| «мб» | пусто — только заголовок «🤒 Список ваших болезней:» |
| «-вирусы» | «❎ Вы отключили оповещения вирусов от Эпидемик» |
| ±лаб | «❇️Внимание, лаборатория рассекречена, …» (без пробела после эмодзи); секретное досье — команда в кавычках "+лаб" |
| -имя лаборатории | название становится «лаб {имя}» |
| Корпорации | все тексты оригинала: карточка, создание («…Либо, используя команду…»), «Принят в корпорацию…», «уже создали свою Корпорацию… "+корп код"», переименование «Название корпорации «X» обновлено», кнопка «Участники» пишет «📝 {игрок} Активировал кнопку» |
| Вакцина | «❌ Недостаточно био-ресурсов! Нужно <b>N</b> 🧬» |
| /start повторно | «💚 Не идентифицируемый объект замечен!» — структура оригинала (гайд, чат, канал, поддержка) |
