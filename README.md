# Эпидемик — Telegram-игра «био-войны»

Текстовая игра для групповых чатов. Это клон ядра «Эпидемик 2.0» с теми же механиками и формулами:
лаборатория, прокачка, заражения, горячка, вакцина, ежедневная премия, биотопы, корпорации и обучение.
Плюс админ-панель владельца.

Стек: Python 3.12, aiogram 3, SQLite. Запуск — Docker Compose, один контейнер.

---

## 1. Подготовка бота в @BotFather

1. `/newbot` — создайте бота и сохраните токен.
2. `/setprivacy` → выберите бота → **Disable**.
   **Без этого бот не видит команды вроде «лаб» и «заразить» в группах.**
   Есть альтернатива: выдать боту права администратора в чате.
3. `/setjoingroups` → **Enable** — чтобы бота можно было добавлять в группы.
4. Узнайте свой Telegram ID, например у @userinfobot. Это будет `ADMIN_ID`.

## 2. Установка на сервер (Ubuntu/Debian)

> **Если на этом токене уже работает другой бот** (например, старый `bot.py`), сначала остановите его.
> Два процесса на одном токене мешают друг другу: в логах будет `TelegramConflictError`, а бот будет
> отвечать через раз. Игроков из старого бота можно перенести — см. раздел 4.

```bash
# Docker (если ещё не установлен)
curl -fsSL https://get.docker.com | sh

# Код бота: загрузите архив на сервер (с вашего компьютера: scp epidemic-bot.tar.gz root@IP_СЕРВЕРА:~)
tar -xzf epidemic-bot.tar.gz
cd epidemic-bot

# Настройки
cp .env.example .env
nano .env          # обязательно: BOT_TOKEN и ADMIN_ID

# Запуск
docker compose up -d --build
```

Проверка:

```bash
docker compose ps          # STATUS: Up (healthy) — примерно через минуту
docker compose logs -f     # в логах: «Бот @имя запущен»
```

Проверка в Telegram:

1. В личке с ботом — `/start`: картинка и кнопки «Начать путешествие / Отказываюсь».
2. Добавьте бота в группу и **сделайте администратором**: без этого не будет прощаний с ушедшими
   участниками, а при включённом privacy mode бот не увидит команды.
3. В группе: `лаб`, ответом на чужое сообщение — `заразить`, затем `мж`, `биотоп`, `помощь`.
4. От имени владельца (`ADMIN_ID`) в личке — `/admin`: откроется админ-панель.

Картинки для обучения лежат в папке `media/` (сейчас там временные заглушки, подробности — в
`media/README.md`). Чтобы заменить картинку, положите файл с тем же именем. Перезапуск не нужен.

## 3. Настройки (`.env`)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (**обязательно**) |
| `ADMIN_ID` | Telegram ID владельца; несколько — через запятую (**обязательно**) |
| `TZ` | часовой пояс ежедневной премии (по умолчанию `Europe/Moscow`) |
| `GAME_NAME` | название игры в служебных текстах (тексты обучения — дословно из оригинала, `epidemic/data/story.yml`) |
| `NOTIFY_TITLE` | заголовок оповещений «🦠 … \| #оповещение» |
| `GUIDE_URL`, `CHAT_URL`, `CHANNEL_URL`, `RULES_URL` | ссылки в меню и в конце обучения (пустые скрываются) |
| `SUPPORT` | контакты поддержки в меню /start |

После изменения `.env`: `docker compose up -d`.

## 4. Обслуживание

| Задача | Команда |
|---|---|
| Логи | `docker compose logs -f --tail 100` |
| Перезапуск | `docker compose restart` |
| Остановка | `docker compose stop` |
| Обновление кода | заменить файлы проекта → `docker compose up -d --build` |
| Резервная копия сейчас | `docker compose exec bot python -m epidemic.backup` (бота останавливать не нужно) |
| Забрать копии на сервер | `docker compose cp bot:/app/data/backups ./backups` |
| Авто-бэкапы | делаются раз в сутки в `/app/data/backups`, хранятся последние 7 |

База лежит в Docker-томе `epidemic_data`. Она переживает пересборку и обновления.
Не выполняйте `docker compose down -v`: флаг `-v` удаляет том вместе с базой.

### Восстановление из копии

```bash
docker compose stop
docker compose cp ./backups/epidemic-YYYYMMDD-HHMMSS.sqlite3 bot:/app/data/restore.sqlite3
docker compose run --rm --user root bot sh -c "\
  cp /app/data/restore.sqlite3 /app/data/epidemic.sqlite3 && \
  rm -f /app/data/epidemic.sqlite3-wal /app/data/epidemic.sqlite3-shm /app/data/restore.sqlite3 && \
  chown bot:bot /app/data/epidemic.sqlite3"
docker compose start
```

Копирование идёт от root, а затем файл отдаётся пользователю `bot`: `docker compose cp` создаёт файлы
от root, и без `chown` бот не смог бы писать в базу. Файлы `-wal`/`-shm` удаляются, потому что
относятся к старой базе.

### Перенос игроков из старого бота (`bot.py`)

```bash
docker compose stop
docker compose cp /путь/к/biowars.sqlite3 bot:/app/data/old.sqlite3
docker compose run --rm bot python -m tools.migrate_from_biowars /app/data/old.sqlite3
docker compose start
```

Переносятся пользователи, лаборатории, корпорации, активные заражения, администраторы, запреты названий,
наказания и изменённые глобальные настройки. Старые навыки сопоставляются так:
квалификация → разработка (максимум 60), хранилище → ёмкость патогенов.

## 5. Команды игроков

Полный список бот показывает по команде `команды` (`помощь` — меню, как в оригинале). Основное:

| Команда | Что делает |
|---|---|
| `/start` (в ЛС) | обучение из 7 шагов; повторно — меню |
| `лаб`, `лаб @user`, ответом `лаб` | досье лаборатории; под своим — кнопки прокачки |
| `+зз [N]` / `++зз [N]` / `-зз N` | цена / прокачать сразу / понизить с возвратом 50 % |
| `заразить @user [N]`, ответом `заразить [N]` | заражение (N — патогены, до 10) |
| `заразить +` / `=` / `-` / `рандом` | случайная цель сильнее / равная / слабее (без уведомления) / любая |
| `мж`, `мб`, `мж топ` | мои жертвы с премией / мои болезни / жертвы по доходу |
| `мф` | массовое заражение «слетевших» жертв (по странице или всех, с остановкой) |
| `кв`, `!купить вакцину` | снять горячку за иммунитет × 15 🧬 |
| `биотоп`, `бч`, `корп топ` | топы |
| `+вирусы` / `-вирусы` | уведомления о заражениях в этот чат / выключить |
| `.корп`, `.корп создать …`, `+корп КОД` … | корпорации |
| `!ид`, `!чат ид` | ID игрока / беседы |
| `правила`, `+правила` (текст с новой строки), `-правила` | правила чата (менять — админы чата) |
| `заметки`, `+заметка Название` (текст с новой строки), `заметка …`, `-заметка …` | заметки беседы |
| `кто админ`, `±приветствия`, `±прощания` | админы чата / прощание с ушедшими (включают админы чата) |
| `обнять`, `кусь`, `погладить`, `дать пять` … (ответом или с @), `ник Имя` | РП-команды, чат-ник |

## 6. Администрирование

`/admin` открывает панель с разделами. Роли: **владелец** (`ADMIN_ID`) → **старший админ** → **админ**.

| Уровень | Команды |
|---|---|
| Админ | `/labinfo`, `/stats`, `/admin_history`, `/disable_lab ID [7d] причина`, `/enable_lab`, `/sanction`, `/sanctions`, `/ban_name`, `/unban_name`, `/names`, `/force_rename`, `админы`; команды оригинала: `эпимут N @user причина` / `-эпимут @user` (запрет на названия на N дней), `эпиас N @user причина` / `-эпиас @user` (игровой мут), `!эпимут`, `!эпиас`, `!чек @user`, `!стата`, `/game_exp`, `/search_pathogen текст` |
| Старший | всё выше + `/give_res`, `/give_xp`, `/set_skill`, `/hide`, `/unhide`, `+админ` / `-админ` |
| Владелец | всё выше + `+старший` / `-старший`, `/set_game_setting`, `тех+` / `тех-`, `+ас` / `-ас` (полный игнор), `!выдать`, `!повысить` / `!понизить` |

Глобальные множители (опыт, премия, стоимость прокачки, скорость производства, горячка, КД, максимальная
разница) меняются командой `/set_game_setting KEY VALUE`. Текущие значения видны в `/admin` → «Глобальные настройки».

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| В группе бот молчит на «лаб» | privacy mode не выключен → @BotFather `/setprivacy` → Disable, затем удалить и снова добавить бота в чат |
| Контейнер `unhealthy` | `docker compose logs` — обычно неверный `BOT_TOKEN` |
| «Данные о субъекте отсутствуют» | игрок ещё ни разу не писал в чат с ботом — бот его не знает |
| Уведомления о заражении не приходят в ЛС | игрок не нажимал /start у бота — Telegram запрещает ботам писать первыми |
